🐍 Перевірка умов у Python

Навчися приймати рішення за допомогою коду!

1. Що таке умова?

Умова — це перевірка, яка визначає, які команди виконає програма.

if

Якщо умова істинна — виконуємо команди.

elif

Перевіряємо іншу умову.

else

Виконуємо команди, якщо попередні умови хибні.

2. Приклад коду Python

a = 8
b = 5

if a > b:
    print("Перше число більше")
elif a < b:
    print("Друге число більше")
else:
    print("Числа рівні")

Оператори порівняння: > більше, < менше, == дорівнює, != не дорівнює.
